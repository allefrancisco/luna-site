Política de privacidade — Luna

Data de vigência: 26 de novembro de 2026

O que a Luna faz

A Luna é uma assistente pessoal de uso privado de Alessandro. Ela acessa o Google Agenda do próprio dono apenas para consultar, criar e alterar eventos quando ele pede.

Como os dados são tratados

Os dados ficam criptografados no servidor do dono. Não são vendidos, compartilhados nem usados para publicidade.

Dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação de acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
